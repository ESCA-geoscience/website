# ESCA Geoscience website

Static website drafts for esca-geosciences.com, served by GitHub Pages from `main`.

| Path | What |
|------|------|
| `index.html` | Chooser page linking the two drafts |
| `v1/` | Version 1: dark product page |
| `v2/` | Version 2: company profile |
| `v3/` | Version 3: editorial |

No build step: each folder is plain HTML with its images in `assets/`.

**Public repo.** Screenshots must never show a well name, survey name, formation name,
coordinates or anything else that identifies an area. Blur or crop them before committing.
